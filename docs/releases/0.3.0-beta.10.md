# Velocity Type 0.3.0-beta.10 — Public Beta

**Status:** Beta version for testing. It may contain bugs and receive further adjustments.

## Highlights

- Quick Play (one click) and New Race (full setup) side by side.
- Automatic difficulty is back as a switch next to the four difficulty levels.
- Cleaner, faster build: unused modules, data and styles removed; quiet console in production.
- Better accessibility (labelled option groups, tabs linked to panels) and full keyboard navigation in menus.

## Before publishing

- [ ] `npm ci`, `npm test`, `npm run build` succeed (or `npm run verify`).
- [ ] Follow `docs/BETA_CHECKLIST.md` (menus by keyboard, 4 screen sizes, both languages).
- [ ] If your repository still has `public/assets/`, run `git rm -r public/assets` (it is no longer shipped).
