# Velocity Type 0.3.0-beta.11 — Public Beta

**Status:** Beta version for testing. It may contain bugs and receive further adjustments.

## Changes

- New `npm run cleanup` removes files left over from earlier versions when a new package is extracted over an old folder.
- `npm run verify` now lists leftover files and prints only the failing tests with their error messages.

## Before publishing

- [ ] Extract the package over your project, then run `npm run cleanup`.
- [ ] `npm ci`, `npm test`, `npm run build` succeed (or `npm run verify`).
- [ ] Follow `docs/BETA_CHECKLIST.md`.
