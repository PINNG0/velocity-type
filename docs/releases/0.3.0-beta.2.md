# Velocity Type 0.3.0-beta.2 — Public Beta

**Status:** versão Beta para testes. Esta versão pode conter erros e receber ajustes.

## Destaques

- Corrida single-player baseada em velocidade de digitação.
- Modos Sprint, Longa e Resistência.
- Idiomas português e inglês, temas selecionáveis e regras de digitação configuráveis.
- Indicadores de WPM, precisão, erros, combo e posição.
- Histórico local e importação/exportação de registros.
- Perfil com XP, níveis, conquistas e objetivos.

## Correções registradas nesta versão

- Corrigido um problema de CSS que podia fazer os carros e a pista desaparecerem.
- Melhorado o diagnóstico de erros de digitação quando o texto inserido tem o mesmo tamanho da frase esperada.

## Antes de publicar

- [ ] Confirmar que `npm ci` termina sem erros.
- [ ] Confirmar que `npm test` passa.
- [ ] Confirmar que `npm run build` passa.
- [ ] Ativar GitHub Pages com a fonte **GitHub Actions** nas configurações do repositório.
- [ ] Testar o endereço publicado em um navegador.
- [ ] Testar iniciar, pausar, retomar e concluir uma corrida.
- [ ] Verificar se histórico e progressão persistem após recarregar a página.

## Como reportar problemas

Ao relatar um problema, inclua o navegador, os passos para reproduzir e o que aconteceu versus o que era esperado. Não inclua dados pessoais ou arquivos de backup contendo informações que não queira compartilhar.
