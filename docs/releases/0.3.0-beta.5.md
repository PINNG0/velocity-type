# Velocity Type 0.3.0-beta.5 — Public Beta

**Status:** Beta version for testing. It may contain bugs and receive further adjustments.

## Highlights

- Full interface in **English and Portuguese** (auto-detected on first visit; EN/PT switch on the main menu).
- **Quick start:** one click to play; advanced options and the garage are tucked into a collapsed panel; one-line instructions on the first race only.
- Better **readability** at small game sizes (907×510, 821×462) and larger cars.
- Clearer race feedback: distance to the rival ahead / your lead, and a pulse on every completed word.
- Previously added: camera follow and parallax scenery, combo turbo, strong mistake feedback, traffic-light start.
