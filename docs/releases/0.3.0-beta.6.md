# Velocity Type 0.3.0-beta.6 — Public Beta

**Status:** Beta version for testing. It may contain bugs and receive further adjustments.

## Highlights

- Prepared for the CrazyGames Basic requirements: relative paths, tiny download, English + Portuguese, no external links or ads, desktop keyboard play.
- Optional CrazyGames SDK integration (only active on the platform): gameplay events, platform mute, user locale and cloud progress.
- Pause with ESC or Tab; leaving fullscreen pauses automatically.
- Consistent game speed at 30/60/144/165 Hz.

## Before publishing

- [ ] `npm ci`, `npm test`, `npm run build` succeed (or `npm run verify`).
- [ ] Zip the **contents** of `dist/` (with `index.html` at the root) and test it in the CrazyGames Preview tool.
- [ ] Check the iframe sizes listed in `docs/CRAZYGAMES.md` (907×510, 821×462, …).
- [ ] Record the two preview videos (landscape and portrait) and upload the three covers from `docs/crazygames/`.
