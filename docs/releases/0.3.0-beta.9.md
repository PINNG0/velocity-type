# Velocity Type 0.3.0-beta.9 — Public Beta

**Status:** Beta version for testing. It may contain bugs and receive further adjustments.

## Highlights

- A single "New race" entry opens the race setup; the race only starts with "Start race".
- Distances Short 1 km / Medium 2 km / Long 5 km and four difficulty levels (Easy, Normal, Hard, Expert).
- Race rules (mistake mode and typing rules) live in the race setup; Settings only hold general options.
- Keyboard navigation in menus: arrows move the visible selection, Enter confirms, Esc goes back; typing during a race is never intercepted.
- Cleaner package: no duplicate background image, consistent lockfile.
